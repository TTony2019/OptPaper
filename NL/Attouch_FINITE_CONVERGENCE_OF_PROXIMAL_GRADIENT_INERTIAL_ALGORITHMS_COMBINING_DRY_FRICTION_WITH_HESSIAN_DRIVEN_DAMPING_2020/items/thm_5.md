## Lean statement
```lean
theorem IPAHDDN_finiteLength {H : Type*} [NormedAddCommGroup H]
    [InnerProductSpace ℝ H] [CompleteSpace H]
    (f phi : H → ℝ) (h gamma beta L r : ℝ) (hdf : DF_r phi r)
    (alg : IPAHDDN f phi.toEReal hdf.toEReal_mem_gammaZero h gamma beta)
    (hf : ContDiff ℝ 1 f)
    (hL : HasLipschitzGradient (gradient f) L) (hL_nonneg : 0 ≤ L)
    (hbelow : ∃ c : ℝ, ∀ x, c ≤ f x)
    (hpositive : 0 < h ∧ 0 < gamma ∧ 0 < beta)
    (hgamma : gamma ≥ (3 * L / 2) * (h + beta)) (hh : L * h ^ 2 ≤ 1) :
    ∃ xInf, HasFiniteLength alg.x ∧ Filter.Tendsto alg.x Filter.atTop (nhds xInf) ∧
      tsum (fun k : {k : ℕ // 1 ≤ k} ↦ ‖alg.x (k.1 + 1) - alg.x k.1‖) ≤
        (1 / r) * ((1 / (2 * h ^ 2)) * (1 + h * gamma - L * h ^ 2 / 2) *
          ‖alg.x 1 - alg.x 0‖ ^ 2 + f (alg.x 1) - sInf (Set.range f)) ∧
      IsDryFrictionCritical phi f xInf ∧ Filter.Tendsto alg.y Filter.atTop (nhds xInf)
```

## Statement explanation
The theorem is stated for a real Hilbert space \(H\), represented in Lean by a normed additive commutative group with an inner product over \(\mathbb R\) and completeness. The two functions are
\[
f:H\to\mathbb R,\qquad \phi:H\to\mathbb R,
\]
and the real parameters are \(h,\gamma,\beta,L,r\). The assumption `hdf : DF_r phi r` is a dry-friction hypothesis on \(\phi\) with radius \(r\). The proof uses from it that \(\phi(0)=0\), that \(r>0\), that the ball of radius \(r\) around \(0\) is contained in the subdifferential \(\partial\phi(0)\), that \(\phi\) is continuous, and that the \(\mathbb R\)-valued extension of \(\phi\) belongs to \(\Gamma_0(H)\). The assumption
\[
\text{`alg : IPAHDDN ...`}
\]
is an algorithm object whose fields `alg.x` and `alg.y` are the two sequences generated by the inertial proximal-gradient algorithm with dry friction and Hessian-driven damping. In this proof the essential algorithm properties used are the extrapolation relation involving `alg.y` and the shifted recurrence satisfied by `alg.x`.

The remaining hypotheses are:
\[
\text{`hf : ContDiff ℝ 1 f`},
\]
so \(f\) is continuously differentiable;
\[
\text{`hL : HasLipschitzGradient (gradient f) L`},
\]
so the gradient \(\nabla f\) is \(L\)-Lipschitz;
\[
\text{`hL_nonneg : 0 ≤ L`};
\]
\[
\text{`hbelow : ∃ c : ℝ, ∀ x, c ≤ f x`},
\]
so \(f\) is bounded below;
\[
\text{`hpositive : 0 < h ∧ 0 < gamma ∧ 0 < beta`};
\]
\[
\gamma \ge \frac{3L}{2}(h+\beta);
\]
and
\[
Lh^2\le 1.
\]

The conclusion asserts the existence of a point \(x_\infty\in H\) such that five things hold. First, the sequence \(x_k=\text{`alg.x` }k\) has finite length:
\[
\sum_{k=0}^{\infty}\|x_{k+1}-x_k\|<\infty.
\]
Second,
\[
x_k\to x_\infty.
\]
Third, there is a quantitative bound on the tail length:
\[
\sum_{k=1}^{\infty}\|x_{k+1}-x_k\|
\le
\frac1r\left(
\frac{1}{2h^2}\left(1+h\gamma-\frac{Lh^2}{2}\right)
\|x_1-x_0\|^2
+f(x_1)-\inf f
\right),
\]
where \(\inf f\) denotes the infimum of the range of \(f\). Fourth, the limit point is dry-friction critical:
\[
-\nabla f(x_\infty)\in \partial\phi(0).
\]
Fifth, the auxiliary sequence \(y_k=\text{`alg.y` }k\) also converges to \(x_\infty\).

Thus the theorem says that under a small-step condition, a positive damping condition, a lower bound on \(f\), and a lower bound on the damping parameter \(\gamma\), the IPAHDDN iterates have summable successive distances, converge to a limit, satisfy a quantitative finite-length estimate, and the limit is a stationary point of the dry-friction inclusion. The same limit also attracts the extrapolated sequence \(y_k\).

```lean
    (hC1.tendsto xInf).comp hxInf_succ
  have hgrad_diff : Filter.Tendsto
      (fun k => gradient f (alg.x (k + 1)) - gradient f (alg.x k)) Filter.atTop (nhds 0) :=
    by simpa using hgrad_succ.sub hgrad
  have hgrad_y : Filter.Tendsto (fun k => gradient f (alg.y k)) Filter.atTop (nhds (gradient f xInf)) :=
    (hC1.tendsto xInf).comp hy
  let q : ℕ → H := fun k => Classical.choose (hshift k)
  have hqmem (k : ℕ) : q k ∈ subdifferential phi (v (k + 1)) :=
    (Classical.choose_spec (hshift k)).1
  have hqrec (k : ℕ) :
      v (k + 1) - v k + gamma • d (k + 1) + h • q k +
        beta • (gradient f (alg.x (k + 1)) - gradient f (alg.x k)) + h • gradient f (alg.y k) = 0 :=
    (Classical.choose_spec (hshift k)).2
  have hqsolve (k : ℕ) :
      h • q k = -(v (k + 1) - v k + gamma • d (k + 1) +
        beta • (gradient f (alg.x (k + 1)) - gradient f (alg.x k)) + h • gradient f (alg.y k)) := by
    apply eq_neg_of_add_eq_zero_left
    calc
      h • q k + (v (k + 1) - v k + gamma • d (k + 1) +
          beta • (gradient f (alg.x (k + 1)) - gradient f (alg.x k)) + h • gradient f (alg.y k)) =
          v (k + 1) - v k + gamma • d (k + 1) + h • q k +
            beta • (gradient f (alg.x (k + 1)) - gradient f (alg.x k)) + h • gradient f (alg.y k) := by ac_rfl
      _ = 0 := hqrec k
  have hdamp : Filter.Tendsto (fun k => gamma • d (k + 1)) Filter.atTop (nhds 0) :=
    by simpa using hd_succ.const_smul gamma
  have hbeta : Filter.Tendsto
      (fun k => beta • (gradient f (alg.x (k + 1)) - gradient f (alg.x k))) Filter.atTop (nhds 0) :=
    by simpa using hgrad_diff.const_smul beta
  have hgrad_term : Filter.Tendsto (fun k => h • gradient f (alg.y k))
      Filter.atTop (nhds (h • gradient f xInf)) := hgrad_y.const_smul h
  have hright : Filter.Tendsto (fun k =>
      -(v (k + 1) - v k + gamma • d (k + 1) +
        beta • (gradient f (alg.x (k + 1)) - gradient f (alg.x k)) + h • gradient f (alg.y k)))
      Filter.atTop (nhds (-(h • gradient f xInf))) := by
    simpa using (((hv_diff.add hdamp).add hbeta).add hgrad_term).neg
  have hq_scaled : Filter.Tendsto (fun k => h • q k) Filter.atTop
      (nhds (h • (-gradient f xInf))) := by
    convert hright using 1
    · ext k
      rw [hqsolve]
    · simp
  have hq : Filter.Tendsto q Filter.atTop (nhds (-gradient f xInf)) := by
    have hq' := hq_scaled.const_smul (1 / h)
    have hqfun : (fun k => (1 / h) • (h • q k)) = q := by
      funext k
      rw [smul_smul]
      field_simp [hh.ne']
      simp
    have hqlim : (1 / h) • (h • (-gradient f xInf)) = -gradient f xInf := by
      rw [smul_smul]
      field_simp [hh.ne']
      simp
    rw [hqfun, hqlim] at hq'
    exact hq'
  have hcritical : IsDryFrictionCritical phi f xInf := by
    unfold IsDryFrictionCritical
    exact convex_subgradient_limit_at_zero phi (fun k => v (k + 1)) q
      (-gradient f xInf) hdf.continuous hv_succ hq hqmem
  exact ⟨xInf, hfinite, hxInf, hlength, hcritical, hy⟩
```

## Proof explanation
Let
\[
x_k=\text{`alg.x` }k,\qquad y_k=\text{`alg.y` }k.
\]
The proof begins by defining the successive differences and the scaled differences:
\[
d_k=x_{k+1}-x_k,\qquad v_k=\frac1h d_k=\frac1h(x_{k+1}-x_k).
\]
Thus \(d_k=h v_k\). Since \(h>0\), this equality also gives
\[
\|d_k\|=h\|v_k\|.
\]

The hypothesis `hpositive` is decomposed into \(h>0\), \(\gamma>0\), and \(\beta>0\). From `hf`, the lemma `continuous_gradient_of_contDiff` gives that \(\nabla f\) is continuous. From `hasFDerivAt_gradient`, the proof records that at every point \(z\), the Fréchet derivative of \(f\) at \(z\) is the linear functional
\[
u\mapsto \langle \nabla f(z),u\rangle,
\]
represented by `innerSL ℝ (gradient f z)`. This fact is used indirectly through the later continuity and convergence arguments for the gradient.

The proof also sets up
\[
1+h\gamma>0,
\]
because \(h\gamma>0\). Hence \(1+h\gamma\neq 0\), which is needed when using the extrapolation relation.

The shifted recurrence is imported from `IPAHDDN_shifted_recurrence`. In the current notation it says that for every \(k\), there exists \(q_k\in H\) such that
\[
q_k\in \partial\phi(v_{k+1})
\]
and
\[
v_{k+1}-v_k+\gamma d_{k+1}+h q_k
+\beta\bigl(\nabla f(x_{k+1})-\nabla f(x_k)\bigr)
+h\nabla f(y_k)=0.
\]
This is exactly the algorithmic subgradient recurrence expressed in the \(v\)-variables. The hypotheses supplied to the cited lemma are \(h>0\), \(\gamma>0\), and the fact that \(\phi\)'s \(\mathbb R\)-valued extension lies in \(\Gamma_0(H)\), which comes from `hdf`.

Next, the proof derives the basic energy inequality `hraw`. It takes the inner product of the shifted recurrence with \(v_{k+1}\). The term
\[
v_{k+1}-v_k
\]
is handled by `IPAHDDN_inner_sub_self_energy_identity`, which states that for any \(u,v\),
\[
\langle u-v,u\rangle
=
\frac12\|u\|^2-\frac12\|v\|^2+\frac12\|u-v\|^2.
\]
Applying this with \(u=v_{k+1}\) and \(v=v_k\) gives the kinetic difference. The damping term satisfies
\[
\langle \gamma d_{k+1},v_{k+1}\rangle
=
\gamma h\|v_{k+1}\|^2,
\]
because \(d_{k+1}=h v_{k+1}\). The term involving \(h q_k\) becomes \(h\langle q_k,v_{k+1}\rangle\), the term involving \(\beta\) becomes \(\beta\) times the corresponding inner product, and the gradient term becomes \(\langle \nabla f(y_k),d_{k+1}\rangle\).

From \(q_k\in\partial\phi(v_{k+1})\), the subdifferential inequality specialized to \(y=0\) gives
\[
\langle -v_{k+1},q_k\rangle+\phi(v_{k+1})\le \phi(0).
\]
Since `hdf` gives \(\phi(0)=0\), this becomes
\[
\phi(v_{k+1})\le \langle q_k,v_{k+1}\rangle.
\]
Multiplying by \(h>0\) and combining with the inner-product identity yields
\[
\frac12\|v_{k+1}\|^2-\frac12\|v_k\|^2+\frac12\|v_{k+1}-v_k\|^2
+\gamma h\|v_{k+1}\|^2+h\phi(v_{k+1})
\]
\[
+\beta\langle \nabla f(x_{k+1})-\nabla f(x_k),v_{k+1}\rangle
+\langle \nabla f(y_k),d_{k+1}\rangle\le 0.
\]

The proof then bounds the friction term. The hypothesis `hdf` supplies the ball condition
\[
\operatorname{ball}(0,r)\subseteq \partial\phi(0),
\]
along with \(\phi(0)=0\) and \(r>0\). The cited theorem `subgradient_ball_exact_linear_lower_bound` then gives
\[
r\|u\|\le \phi(u)
\]
for every \(u\in H\). Applying this to \(u=v_{k+1}\) and multiplying by \(h>0\) gives
\[
r\|d_{k+1}\|=rh\|v_{k+1}\|\le h\phi(v_{k+1}).
\]
Thus the subgradient term controls the successive distance term.

The smooth descent estimate is obtained from `IPAHDDN_smooth_descent_of_fderiv_lipschitz`, which says that if \(f\) is \(C^1\) and \(\nabla f\) is \(L\)-Lipschitz, then for all \(x,y\),
\[
f(y)\le f(x)+\langle \nabla f(x),y-x\rangle+\frac L2\|y-x\|^2.
\]
This is the standard descent inequality following from integrating the Lipschitz bound on the gradient.

Two cross-term estimates are then proved. From the Lipschitz property,
\[
\|\nabla f(x_{k+1})-\nabla f(x_k)\|\le L\|d_k\|.
\]
Using Cauchy-Schwarz and then Young's inequality \(2ab\le a^2+b^2\), the proof obtains
\[
\beta\langle \nabla f(x_{k+1})-\nabla f(x_k),v_{k+1}\rangle
\le
\frac{\beta hL}{2}\bigl(\|v_k\|^2+\|v_{k+1}\|^2\bigr).
\]
It also obtains the corresponding upper bound for the negative of that inner product:
\[
-\beta\langle \nabla f(x_{k+1})-\nabla f(x_k),v_{k+1}\rangle
\le
\frac{\beta hL}{2}\bigl(\|v_k\|^2+\|v_{k+1}\|^2\bigr).
\]
The second version is needed because the energy difference will contain the cross term with a sign that must be dominated by a positive quantity.

The proof also controls the gradient term \(\langle \nabla f(y_k),d_{k+1}\rangle\). The algorithm's extrapolation relation gives
\[
y_k-x_{k+1}=\frac1{1+h\gamma}d_k.
\]
Therefore
\[
\|x_{k+1}-y_k\|=\frac{\|d_k\|}{1+h\gamma}.
\]
Applying the smooth descent inequality with \(x=x_{k+1}\) and \(y=x_{k+2}\), and splitting
\[
\nabla f(x_{k+1})
=
\nabla f(y_k)
+
\bigl(\nabla f(x_{k+1})-\nabla f(y_k)\bigr),
\]
the proof bounds the second part by Lipschitz continuity and obtains
\[
f(x_{k+2})-f(x_{k+1})
-\frac L2\|d_{k+1}\|^2
-\frac{L}{1+h\gamma}\|d_k\|\|d_{k+1}\|
\le
\langle \nabla f(y_k),d_{k+1}\rangle.
\]

A key algebraic input is `IPAHDDN_parameter_quadratic_nonneg`. Applied with
\[
a=\|v_{k+1}\|,\qquad b=\|v_k\|,
\]
it states that
\[
0\le
\left(
\frac{1+h\gamma-\frac{Lh^2}{2}-\frac{3\beta hL}{2}}{2}
+\frac{\beta hL}{4}
\right)(a^2+b^2)
-
\left(1+\frac{Lh^2}{1+h\gamma}\right)ab.
\]
The hypotheses needed are exactly \(h>0\), \(\beta>0\), \(L\ge0\), \(\gamma\ge \frac{3L}{2}(h+\beta)\), and \(a,b\ge0\). This quadratic nonnegativity is what allows the proof to absorb the cross terms that appear after applying Young's inequality.

The proof then defines the energy
\[
E_k=
\frac{1+h\gamma-\frac{Lh^2}{2}}{2}\|v_k\|^2
+f(x_{k+1})-\inf f,
\]
where \(\inf f\) is the infimum of the range of \(f\). Using the previously collected estimates, together with the triangle inequality for norms,
\[
\bigl|\|v_{k+1}\|-\|v_k\|\bigr|\le \|v_{k+1}-v_k\|,
\]
and hence
\[
\|v_{k+1}\|^2+\|v_k\|^2-2\|v_{k+1}\|\|v_k\|
\le
\|v_{k+1}-v_k\|^2,
\]
the proof obtains
\[
E_{k+1}-E_k+r\|d_{k+1}\|\le 0.
\]
The tactic `ring_nf` expands and normalizes the algebraic expressions, and `nlinarith` then combines the inequalities linearly and nonlinearly.

Next the proof shows \(E_k\ge0\). Since \(f\) is bounded below, the range of \(f\) is bounded below, so the infimum satisfies
\[
\inf f\le f(x_{k+1}).
\]
Also, the coefficient
\[
\frac{1+h\gamma-\frac{Lh^2}{2}}{2}
\]
is nonnegative. Indeed, from
\[
\gamma\ge \frac{3L}{2}(h+\beta)
\]
and \(h>0\), one has
\[
h\gamma\ge \frac{3L}{2}h(h+\beta),
\]
which is enough to imply
\[
1+h\gamma-\frac{Lh^2}{2}\ge0.
\]
Therefore every term in \(E_k\) is nonnegative.

Using the inequality
\[
E_{k+1}-E_k+r\|d_{k+1}\|\le0
\]
and telescoping, the proof obtains for every \(N\),
\[
E_N+\sum_{k=0}^{N-1}r\|d_{k+1}\|\le E_0.
\]
Since \(E_N\ge0\), this gives
\[
\sum_{k=0}^{N-1}\|d_{k+1}\|\le \frac{E_0}{r}.
\]
Because the summands are nonnegative and all partial sums are bounded by \(E_0/r\), the standard summability criterion `summable_of_sum_range_le` yields
\[
\sum_{k=0}^{\infty}\|d_{k+1}\|<\infty.
\]
Then `IPAHDDN_summable_of_summable_succ` removes the shift: if \(\sum_k a(k+1)\) converges, then \(\sum_k a(k)\) converges. Applying this to \(a(k)=\|d_k\|\), the proof gets
\[
\sum_{k=0}^{\infty}\|d_k\|<\infty.
\]
By the definition of `HasFiniteLength`, this is exactly
\[
\operatorname{HasFiniteLength}(x).
\]

Now the finite-length convergence result `IPAHDDN_finite_length_tendsto` is applied. It states that if \(x:\mathbb N\to H\) has summable successive distances, then there exists \(x_\infty\in H\) such that
\[
x_k\to x_\infty.
\]
Its mathematical content is that a sequence whose successive distances are summable is Cauchy, and completeness of \(H\) gives convergence. Thus the proof obtains \(x_\infty\) and the convergence \(x_k\to x_\infty\).

The quantitative bound on the total variation is obtained by passing from partial sums to the full sum. The theorem `Real.tsum_le_of_sum_range_le` is used with the already established partial-sum bound to get
\[
\sum_{k=0}^{\infty}\|d_{k+1}\|\le \frac{E_0}{r}.
\]
Then `tsum_subtype_succ_reindex` is applied to reindex the sum over the subtype \(\{k\in\mathbb N:1\le k\}\). It states that
\[
\sum_{k\ge1} a(k)=\sum_{n=0}^{\infty}a(n+1).
\]
Taking \(a(k)=\|d_k\|\), this gives
\[
\sum_{k\ge1}\|x_{k+1}-x_k\|
=
\sum_{n=0}^{\infty}\|d_{n+1}\|
\le \frac{E_0}{r}.
\]
Finally the proof expands \(E_0\). Since
\[
v_0=\frac1h(x_1-x_0),
\]
we have
\[
E_0=
\frac{1+h\gamma-\frac{Lh^2}{2}}{2}
\left\|\frac1h(x_1-x_0)\right\|^2
+f(x_1)-\inf f
\]
\[
=
\frac{1}{2h^2}
\left(1+h\gamma-\frac{Lh^2}{2}\right)
\|x_1-x_0\|^2
+f(x_1)-\inf f.
\]
Division by \(r>0\) gives the displayed bound in the theorem.

The proof next studies convergence of the differences and of the auxiliary sequence. Since
\[
\sum_k\|d_k\|<\infty,
\]
the terms tend to zero:
\[
\|d_k\|\to0.
\]
Hence \(d_k\to0\), and therefore \(d_{k+1}\to0\). Since \(v_k=\frac1h d_k\), also
\[
v_k\to0,\qquad v_{k+1}\to0,\qquad v_{k+1}-v_k\to0.
\]
The sequence \(x_{k+1}\) converges to \(x_\infty\) because \(x_k\to x_\infty\). The extrapolation relation gives
\[
y_k-x_{k+1}=\frac1{1+h\gamma}d_k\to0.
\]
Therefore
\[
y_k=(y_k-x_{k+1})+x_{k+1}\to 0+x_\infty=x_\infty.
\]
This proves the final convergence assertion for `alg.y`.

It remains to prove the dry-friction criticality of \(x_\infty\). From the shifted recurrence, the proof chooses for each \(k\) a vector \(q_k\) such that
\[
q_k\in\partial\phi(v_{k+1})
\]
and
\[
v_{k+1}-v_k+\gamma d_{k+1}+h q_k
+\beta(\nabla f(x_{k+1})-\nabla f(x_k))
+h\nabla f(y_k)=0.
\]
Solving for \(h q_k\),
\[
h q_k=
-\left(
v_{k+1}-v_k+\gamma d_{k+1}
+\beta(\nabla f(x_{k+1})-\nabla f(x_k))
+h\nabla f(y_k)
\right).
\]
As \(k\to\infty\), the right-hand side converges to \(-h\nabla f(x_\infty)\). Indeed, \(v_{k+1}-v_k\to0\), \(\gamma d_{k+1}\to0\), and
\[
\nabla f(x_{k+1})-\nabla f(x_k)\to0,
\]
because \(x_k\to x_\infty\), \(x_{k+1}\to x_\infty\), and \(\nabla f\) is continuous. Also \(y_k\to x_\infty\), so
\[
h\nabla f(y_k)\to h\nabla f(x_\infty).
\]
Thus
\[
h q_k\to -h\nabla f(x_\infty).
\]
Multiplying by the scalar \(1/h\), using \(h>0\), gives
\[
q_k\to -\nabla f(x_\infty).
\]

Finally, the theorem `convex_subgradient_limit_at_zero` is applied with
\[
u_k=v_{k+1}\to0,\qquad q_k\to -\nabla f(x_\infty),
\]
and with the hypotheses \(q_k\in\partial\phi(v_{k+1})\) and \(\phi\) continuous. The cited result states that if a continuous convex function \(\phi\) is such that \(u_n\to0\), \(q_n\to q_0\), and \(q_n\in\partial\phi(u_n)\) for every \(n\), then \(q_0\in\partial\phi(0)\). Applying it here gives
\[
-\nabla f(x_\infty)\in\partial\phi(0),
\]
which is exactly the definition of `IsDryFrictionCritical phi f xInf`.

Combining finite length, convergence of \(x_k\), the quantitative sum bound, dry-friction criticality of the limit, and convergence of \(y_k\), the proof concludes the required existential statement.
