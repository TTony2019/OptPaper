def IsSmoothAt (C : Set H) (xbar : H) : Prop :=
  xbar ∈ C ∧ ∃ (u : H), u ≠ 0 ∧ normalCone C xbar = {v | ∃ (t : ℝ), t ≥ 0 ∧ v = t • u}

## Statement explanation

The visible fragment does not show the surrounding variable declarations for $H$, but the expression uses $0$ and scalar multiplication by real numbers, so $H$ is being used as an ambient space in which those operations are available. The predicate is defined by

$$
\mathrm{IsSmoothAt}(C,\bar{x})
\iff
\bar{x} \in C
\;\wedge\;
\exists u : H,\;
u \neq 0
\;\wedge\;
\mathrm{normalCone}(C,\bar{x})
=\{\,v \mid \exists t : \mathbb{R},\; t \ge 0 \;\wedge\; v = t \cdot u\,\}.
$$

The first conjunct, $\bar{x} \in C$, says that the point at which smoothness is being asserted actually belongs to the set $C$. The second conjunct says that there exists a nonzero vector $u \in H$ such that the normal cone to $C$ at $\bar{x}$ is exactly the set of all real nonnegative multiples of $u$. Since $t \ge 0$, this set contains $0$ by taking $t=0$, and contains $u$ by taking $t=1$; since $u \neq 0$, the ray is nontrivial. Thus the normal cone is required to be a single nonnegative half-line generated by $u$, rather than a larger cone, a smaller set, or the zero cone alone.

The declaration does not define `normalCone`; it treats $\mathrm{normalCone}(C,\bar{x})$ as an already available set of vectors in $H$ and imposes the displayed equality on it. No convexity, closedness, differentiability, or regularity hypotheses on $C$ appear in the statement. In ordinary language, the definition says that $C$ is smooth at $\bar{x}$ in this formal sense precisely when $\bar{x}$ lies in $C$ and the normal cone to $C$ at $\bar{x}$ is a nonzero nonnegative ray.
