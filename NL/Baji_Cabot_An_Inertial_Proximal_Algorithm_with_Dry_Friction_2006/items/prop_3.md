## Lean statement
```lean
theorem prop_4_1_eventual_alternative [FiniteDimensional ℝ H] (A B : SetValuedOperator H H)
    (hA : IsMaximalMonotone A) (hdomA : A.dom = Set.univ) (hAzero_int : (0 : H) ∈ interior (A (0 : H)))
    (f : H → EReal) (hfinite : ∀ x, f x ≠ ⊤ ∧ f x ≠ ⊥)
    (hf_conv : ∀ x y : H, ∀ a b : ℝ, 0 ≤ a → 0 ≤ b → a + b = 1 →
      f (a • x + b • y) ≤ (a : EReal) * f x + (b : EReal) * f y)
    (hf_C1 : ContDiff ℝ 1 (fun x => (f x).toReal))
    (hinf : ∃ m : ℝ, ∀ x, (m : EReal) ≤ f x)
    (hB_eq_grad : B =
      SetValuedOperator.ofFunction Set.univ
        (fun x : (Set.univ : Set H) => gradient (fun y => (f y).toReal) x.1))
    (lam : ℕ → ℝ) (hlam_pos : ∀ n, lam n > 0) (hlam_nondec : ∀ n, lam n ≤ lam (n+1))
    (x : ℕ → H) (halg : AlgorithmA A B x lam) (xInf : H) (hxInf : Tendsto x atTop (𝓝 xInf))
    (h_smooth : IsSmoothAt (A (0 : H)) (-gradient (fun y => (f y).toReal) xInf))
    (D : Set ℕ) (hD2 : D = stationaryIndices x)
    (u : H) (hu_norm : ‖u‖ = 1)
    (R : ℕ → ℝ)
    (hR : R = fun (n : ℕ) => ∑' (k : ℕ), ‖x (n+k+1) - x (n+k)‖)
    (hu_normal : normalCone (A (0 : H)) (-gradient (fun y => (f y).toReal) xInf) =
      {v | ∃ (t : ℝ), t ≥ 0 ∧ v = t • u})
    (hnot_finite : ¬ ∃ N, ∀ n ≥ N, x n = x N) :
    (∃ N, ∀ n ≥ N, x n = xInf) ∨ (∃ N, ∀ n ≥ N, ‖x n - xInf‖ > 0)
```

## Statement explanation
The theorem is an eventual-alternative result for the iterates $x_n$ of an inertial proximal algorithm with dry friction. The ambient space is $H$, assumed finite-dimensional over $\mathbb R$ in the visible typeclass, with the norm, gradient, interior, and normal-cone structure supplied by the surrounding context. The data are two set-valued operators $A,B:H\rightrightarrows H$, an extended-real-valued function $f:H\to \overline{\mathbb R}$, a sequence of positive nondecreasing steps $\lambda_n$, and an algorithm-generated sequence $x:\mathbb N\to H$.

The hypotheses say that $A$ is maximal monotone, has full domain $H$, and satisfies $0\in \mathrm{int} A(0)$. The function $f$ is finite-valued everywhere, convex, bounded below by some real constant $m$, and its real-valued part $g(x)=(f x)_{\mathbb R}$ is $C^1$. The operator $B$ is exactly the set-valued operator associated with the gradient of $g$ over all of $H$. The sequence $x$ is generated by Algorithm A with step sizes $\lambda$. The sequence converges to a point $x_\infty$, and a smoothness condition $\mathrm{IsSmoothAt}(A(0),-\nabla g(x_\infty))$ holds. A set $D$ is specified to be the stationary-index set of $x$. A unit vector $u$, $\|u\|=1$, spans the normal cone of $A(0)$ at $-\nabla g(x_\infty)$ as the nonnegative ray

$$
\mathrm{normalCone}(A(0),-\nabla g(x_\infty))
=
\{t u:t\ge 0\}.
$$

The function $R$ is defined by

$$
R_n=\sum_{k=0}^{\infty}\|x_{n+k+1}-x_{n+k}\|,
$$

the tail sum of the norms of consecutive increments. Finally, $x$ is not eventually constant: there is no $N$ such that $x_n=x_N$ for all $n\ge N$.

The conclusion is the disjunction

$$
\bigl(\exists N,\ \forall n\ge N,\ x_n=x_\infty\bigr)
\ \vee\
\bigl(\exists N,\ \forall n\ge N,\ \|x_n-x_\infty\|>0\bigr).
$$

Thus, eventually the iterates either stabilize exactly at the limit $x_\infty$, or they remain at strictly positive distance from $x_\infty$.

## Lean proof
```lean
by
  right
  have hth31 : Theorem31Assumptions A B f lam x :=
    prop41_theorem31_assumptions A B hA hdomA hAzero_int f hfinite hf_conv hf_C1 hinf
      hB_eq_grad lam hlam_pos hlam_nondec x halg
  have hsum_norm : Summable (fun n => ‖x (n + 1) - x n‖) :=
    prop41_increment_norm_summable A B f lam x hth31
  have hR_pos : ∀ n, 0 < R n := by
    intro n
    rw [hR]
    let s : ℕ → ℝ := fun k => ‖x (n + k + 1) - x (n + k)‖
    have hs_tail : Summable s := by
      simpa [s, Nat.add_assoc, Nat.add_comm, Nat.add_left_comm] using
        (summable_nat_add_iff (f := fun i => ‖x (i + 1) - x i‖) n).mpr hsum_norm
    have hs_nonneg : ∀ k, 0 ≤ s k := by
      intro k
      exact norm_nonneg _
    have hexists : ∃ k, 0 < s k := by
      by_contra hnone
      have hzero : ∀ k, x (n + k + 1) = x (n + k) := by
        intro k
        have hnot_pos : ¬ 0 < s k := by
          intro hk
          exact hnone ⟨k, hk⟩
        have hle0 : s k ≤ 0 := le_of_not_gt hnot_pos
        have hz : s k = 0 := le_antisymm hle0 (hs_nonneg k)
        have hsub : x (n + k + 1) - x (n + k) = 0 := norm_eq_zero.mp hz
        exact sub_eq_zero.mp hsub
      have htail_const : ∀ k, x (n + k) = x n := by
        intro k
        induction k with
        | zero => simp
        | succ k ih =>
            calc
              x (n + Nat.succ k) = x (n + k) := by
                simpa [Nat.succ_eq_add_one, Nat.add_assoc] using hzero k
              _ = x n := ih
      exact hnot_finite ⟨n, by
        intro m hm
        rcases Nat.exists_eq_add_of_le hm with ⟨k, hk⟩
        subst hk
        exact htail_const k⟩
    rcases hexists with ⟨k, hk⟩
    exact Summable.tsum_pos hs_tail hs_nonneg k hk
  have hnorm_equiv :=
    prop_4_1_norm_equiv A B hA hdomA hAzero_int f hfinite hf_conv hf_C1 hinf hB_eq_grad
      lam hlam_pos hlam_nondec x halg xInf hxInf h_smooth D hD2 u hu_norm R hR hu_normal
      hnot_finite
  have hpos_eventual : ∀ᶠ n in atTop, 0 < ‖x n - xInf‖ :=
    hnorm_equiv.eventually_pos (Eventually.of_forall hR_pos)
  rcases eventually_atTop.mp hpos_eventual with ⟨N, hN⟩
  exact ⟨N, fun n hn => hN n hn⟩
```

## Proof explanation
The proof begins with `right`, so it chooses to prove the right-hand disjunct

$$
\exists N,\ \forall n\ge N,\ \|x_n-x_\infty\|>0.
$$

It does not assume that the left disjunct is false; it simply constructs the second alternative.

First, the proof invokes `prop41_theorem31_assumptions`. That result takes the maximal-monotonicity hypothesis on $A$, the full-domain condition, the condition $0\in \mathrm{int} A(0)$, the finiteness, convexity, $C^1$-smoothness, and boundedness-below of $f$, the identification of $B$ with the gradient operator of $g$, the positivity and monotonicity of the step sizes $\lambda$, and the Algorithm A hypothesis on $x$, and concludes

$$
\mathrm{Theorem31Assumptions}(A,B,f,\lambda,x).
$$

So this step packages the standing hypotheses of the convergence theory into the named assumption set needed for the next estimate.

Next, `prop41_increment_norm_summable` is applied to that assumption package. Its conclusion is

$$
\sum_{n=0}^{\infty}\|x_{n+1}-x_n\|<\infty,
$$

i.e. the sequence of consecutive increment norms is summable. This means the iterates have finite total variation. In particular, every tail of the increment sequence is also summable.

The proof then establishes

$$
\forall n,\quad R_n>0.
$$

For fixed $n$, the definition of $R$ is unfolded by `rw [hR]`, so the goal becomes

$$
0<\sum_{k=0}^{\infty}\|x_{n+k+1}-x_{n+k}\|.
$$

The sequence

$$
s_k=\|x_{n+k+1}-x_{n+k}\|
$$

is introduced. The lemma `summable_nat_add_iff` is used to show that $s$ is summable: it says that shifting a summable sequence by $n$ preserves summability. Indeed,

$$
s_k=\|x_{n+k+1}-x_{n+k}\|=\|x_{(n+k)+1}-x_{n+k}\|,
$$

so $s$ is the $n$-th tail of the summable sequence $k\mapsto \|x_{k+1}-x_k\|$. The `simpa` call normalizes the arithmetic $n+k+1$ versus $n+(k+1)$, and the result is `hs_tail : Summable s`.

The proof also records that every $s_k$ is nonnegative, by `norm_nonneg`.

Then it proves that some $s_k$ is strictly positive. Suppose, for contradiction, that no $s_k$ is positive. Since each $s_k\ge 0$, this forces $s_k=0$ for every $k$. Hence

$$
\|x_{n+k+1}-x_{n+k}\|=0,
$$

so by `norm_eq_zero.mp`,

$$
x_{n+k+1}-x_{n+k}=0,
$$

and therefore

$$
x_{n+k+1}=x_{n+k}.
$$

By induction on $k$, all tail terms from index $n$ onward are equal:

$$
x_{n+k}=x_n\quad\text{for all }k.
$$

If $m\ge n$, then `Nat.exists_eq_add_of_le` gives $m=n+k$ for some $k$, so $x_m=x_n$. Thus $x$ is eventually constant, contradicting the hypothesis that there is no $N$ with $x_n=x_N$ for all $n\ge N$. Therefore some $k$ satisfies $s_k>0$.

Now `Summable.tsum_pos` is applied to the summable sequence $s$, its nonnegativity, and the existence of a positive term. It gives

$$
\sum_{k=0}^{\infty}s_k>0,
$$

which is exactly

$$
R_n>0.
$$

Thus $R_n$ is strictly positive for every $n$. Mathematically, this says that a non-eventually-constant sequence cannot have a tail whose total variation is zero; every remaining tail has positive total variation.

Next, the proof applies `prop_4_1_norm_equiv`. This cited theorem has the same long list of hypotheses as the current statement, including the finite-dimensionality, the maximal monotonicity and domain conditions on $A$, the convexity and smoothness assumptions on $f$, the gradient identification of $B$, the positive nondecreasing step sizes, the Algorithm A hypothesis, convergence $x_n\to x_\infty$, the smoothness condition at $A(0)$ and $-\nabla g(x_\infty)$, the definition of $D$, the unit normal direction $u$, the definition of $R$, the normal-cone condition, and the non-eventual-constancy hypothesis. Its conclusion is the asymptotic equivalence

$$
(n\mapsto \|x_n-x_\infty\|)\sim_{\mathrm{atTop}} R.
$$

In words, the distance from $x_n$ to the limit is asymptotically equivalent to the tail total variation $R_n$.

Since $R_n>0$ for every $n$, the proof has

$$
\forall n,\quad 0<R_n.
$$

Using `Eventually.of_forall`, this becomes the eventual statement that $R_n>0$ eventually along $n\to\infty$. The method `eventually_pos` of the asymptotic equivalence transfers eventual positivity from $R$ to the norm sequence. That is, because

$$
\|x_n-x_\infty\|\sim_{\mathrm{atTop}} R_n
\quad\text{and}\quad
R_n>0\text{ eventually,}
$$

it follows that

$$
\|x_n-x_\infty\|>0
\text{ eventually.}
$$

Thus the proof obtains

$$
\forall^{\mathrm{atTop}} n,\quad 0<\|x_n-x_\infty\|.
$$

Finally, `eventually_atTop.mp` converts this eventual statement into a threshold form: there exists $N$ such that for all $n\ge N$,

$$
\|x_n-x_\infty\|>0.
$$

This is precisely the right-hand disjunct of the desired conclusion, so the proof finishes by providing the witness $N$. Hence the theorem establishes the eventual alternative: either exact eventual stabilization at $x_\infty$, or eventual strict positive distance from $x_\infty$.
