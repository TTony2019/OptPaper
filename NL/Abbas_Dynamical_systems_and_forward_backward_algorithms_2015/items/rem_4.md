## Lean statement
```lean
theorem variable_relaxation_convergence {H : Type*} [NormedAddCommGroup H] [InnerProductSpace ℝ H]
    [CompleteSpace H]
    (Phi : H → Set.Ioi (⊥ : EReal)) (hPhi : Phi ∈ ERealFunction.gammaZero H)
    (S : Set H) (B : H → H) (mu : ℝ) (h : ℕ → ℝ) (beta delta eps : ℝ)
    (alg : VariableRelaxationBackwardForwardAlgorithm Phi hPhi B mu h)
    (heps : 0 < eps) (hsteps : ∀ k, eps ≤ h k ∧ h k ≤ delta - eps)
    (hmu : 0 < mu ∧ mu < 2 * beta) (hdelta : delta = 1 / 2 + min 1 (beta / mu))
    (hS : S.Nonempty)
    (hB : CocoerciveOn beta Set.univ (fun w : Set.univ ↦ B w))
    (hsolution : ∀ z, z ∈ S ↔ -B z ∈ ERealFunction.subdifferential Phi z)
    :
    ∃ ybar, ERealFunction.scaledProximityOperator Phi hPhi ⟨mu, hmu.1⟩ ybar ∈ S ∧
      Tendsto (fun k ↦ toWeakSpace ℝ H (alg.y k)) atTop
        (nhds (toWeakSpace ℝ H ybar))
```

## Statement explanation
The theorem is proved in a real Hilbert-space setting. The type variable `H` is arbitrary, with instances stating that `H` is a normed additive commutative group, a real inner product space, and complete; together these make `H` a real Hilbert space. `Phi` is a function from `H` to the extended real numbers `EReal`, with values required to lie strictly above the bottom element `⊥`. The hypothesis `hPhi` says `Phi` lies in `ERealFunction.gammaZero H`, i.e. it is admitted as a suitable closed, proper, convex extended-real-valued function on `H`. `S` is a subset of `H`, `B : H → H` is an operator, `mu` is a real parameter, `h : ℕ → ℝ` is a sequence of real step sizes, and `beta`, `delta`, and `eps` are real constants. The object `alg` is a variable-relaxation backward-forward algorithm built from `Phi`, `hPhi`, `B`, `mu`, and `h`; in particular, `alg.y` is the iterate sequence generated by the algorithm.

The remaining hypotheses are as follows. `heps` says `eps > 0`. `hsteps` says that for every natural number `k`, the step `h k` lies between `eps` and `delta - eps`; hence the step sizes stay uniformly inside an interval. `hmu` says `mu > 0` and `mu < 2 * beta`. `hdelta` fixes `delta` as the explicit expression `delta = 1 / 2 + min 1 (beta / mu)`. `hS` says `S` is nonempty. `hB` says that the operator `B`, viewed by restriction on the whole space, is `beta`-cocoercive on all of `H`. Finally, `hsolution` says that for every point `z`, the membership `z ∈ S` is equivalent to the subdifferential inclusion `-B z ∈ ERealFunction.subdifferential Phi z`; this is the usual first-order equilibrium condition.

The conclusion states that there exists a point `ybar` in `H` such that the value of the scaled proximity operator of `Phi` with parameter `mu`, evaluated at `ybar`, belongs to `S`; moreover, the sequence of iterates `alg.y k` converges weakly to `ybar`. Weak convergence is expressed by saying that the image of `alg.y k` under `toWeakSpace ℝ H` tends, in the weak topology, to the image of `ybar`.

## Lean proof
```lean
by
  let P : H → H := ERealFunction.scaledProximityOperator Phi hPhi ⟨mu, hmu.1⟩
  let T : H → H := fun y ↦ P y - mu • B (P y)
  have hP : FirmlyNonexpansive P := by
    simpa [P, ERealFunction.scaledProximityOperator] using
      ERealFunction.proximityOperator_firmlyNonexpansive_of_mem_gammaZero
        (ERealFunction.smul_mem_gammaZero Phi hPhi ⟨mu, hmu.1⟩)
  have hTlip : LipschitzWith 1 T := by
    simpa [T, P, Function.comp_def] using
      (forward_step_lipschitz_one_local B beta mu hmu hB).comp
        (lipschitzWith_one_of_firmlyNonexpansive hP)
  have hC : (Function.fixedPoints T).Nonempty := by
    rcases hS with ⟨z, hz⟩
    refine ⟨z - mu • B z, ?_⟩
    have hzfix := fixed_backward_forward_solution_implies_fixed_local Phi hPhi B mu hmu.1 z
      ((hsolution z).1 hz)
    change T (z - mu • B z) = z - mu • B z
    dsimp [T, P]
    rw [hzfix]
  have hC₀ := hC
  obtain ⟨p₀, hp₀⟩ := hC₀
  have hupdate : ∀ n, alg.y (n + 1) = (1 - h n) • alg.y n + h n •
      (P (alg.y n) - mu • B (P (alg.y n))) := by
    intro n
    rw [alg.forward_step n, alg.prox_step n]
  have hseq₀ := variable_relaxation_distance_and_residual_tendsto_local
    P B beta mu delta eps h hmu heps hdelta hsteps hB hP alg.y hupdate p₀
    (by simpa [T] using hp₀)
  have hbounded : Bornology.IsBounded (Set.range alg.y) :=
    bounded_range_of_convergent_distance_to_point hseq₀.1
  have hdist : ∀ z ∈ Function.fixedPoints T, ∃ l : ℝ,
      Tendsto (fun n ↦ ‖alg.y n - z‖) atTop (nhds l) := by
    intro z hz
    exact (variable_relaxation_distance_and_residual_tendsto_local
      P B beta mu delta eps h hmu heps hdelta hsteps hB hP alg.y hupdate z
      (by simpa [T] using hz)).1
  have hcluster : ∀ z : H,
      IsSequentialClusterPt (fun n ↦ toWeakSpace ℝ H (alg.y n))
        (toWeakSpace ℝ H z) → z ∈ Function.fixedPoints T := by
    intro z hz
    rcases hz with ⟨phi, hphi, hphiweak⟩
    have hres : Tendsto (fun n ↦ alg.y (phi n) - T (alg.y (phi n))) atTop (nhds 0) := by
      simpa [T] using hseq₀.2.comp hphi.tendsto_atTop
    rcases isBounded_iff_forall_norm_le.mp hbounded with ⟨C, hCbound⟩
    have hsubbound : ∃ K : ℝ, ∀ n, ‖alg.y (phi n) - z‖ ≤ K := by
      refine ⟨C + ‖z‖, ?_⟩
      intro n
      calc
        ‖alg.y (phi n) - z‖ ≤ ‖alg.y (phi n)‖ + ‖z‖ := norm_sub_le _ _
        _ ≤ C + ‖z‖ := add_le_add (hCbound _ (Set.mem_range_self (phi n))) le_rfl
    have hphiweak' : Tendsto (fun n ↦ toWeakSpace ℝ H (alg.y (phi n))) atTop
        (nhds (toWeakSpace ℝ H z)) := by
      simpa [Function.comp_def] using hphiweak
    exact nonexpansive_eq_of_tendsto_weakly_of_residual_tendsto_zero_local T hTlip
      (fun n ↦ alg.y (phi n)) z hphiweak' hres hsubbound
  rcases opial_lemma hC alg.y hdist hcluster with ⟨ybar, hybar, hyweak⟩
  exact ⟨ybar, fixed_backward_forward_prox_mem_solution_local Phi hPhi S B mu hmu.1
    hsolution ybar (by simpa [T, P] using hybar), hyweak⟩
```

## Proof explanation
The proof first introduces two local definitions. It sets
\[
P = \operatorname{scaledProximityOperator}(\Phi,\mu),
\]
so `P` is the backward proximal step, and it sets
\[
T(y)=P(y)-\mu B(P(y)),
\]
so `T` is the forward-backward operator obtained by applying a forward step to the prox point. The goal is then to prove that `T` has enough fixed-point properties to force weak convergence of the generated sequence.

The first major step is to prove that `P` is firmly nonexpansive. The `have hP` statement does this by invoking the library result that proximity operators of functions in the relevant `Gamma0` class are firmly nonexpansive. The command `simpa [P, ERealFunction.scaledProximityOperator]` rewrites the definition of the scaled proximity operator so that the theorem can be applied to the scaled function obtained from `Phi`, using positivity of `mu`.
