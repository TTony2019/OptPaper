## Lean statement
```lean
theorem forward_backward_stepsize_convergence {H : Type*} [NormedAddCommGroup H]
    [InnerProductSpace ℝ H] [CompleteSpace H]
    (Phi : H → Set.Ioi (⊥ : EReal)) (hPhi : Phi ∈ ERealFunction.gammaZero H)
    (B : H → H) (S : Set H) (h beta : ℝ)
    (alg : ForwardBackwardAlgorithm Phi hPhi B h)
    (hh : 0 < h ∧ h < 2 * beta)
    (hS : S.Nonempty)
    (hB : CocoerciveOn beta Set.univ (fun w : Set.univ ↦ B w))
    (hsolution : ∀ z, z ∈ S ↔ -B z ∈ ERealFunction.subdifferential Phi z) :
    ∃ z ∈ S,
      Filter.Tendsto (fun k ↦ toWeakSpace ℝ H (alg.x k)) Filter.atTop
        (nhds (toWeakSpace ℝ H z))
```

## Statement explanation
The theorem states: Let `H` be a real inner product space that is also a normed additive commutative group and is complete. Fix `h`, `beta` real numbers. Let `Phi` be a function from `H` into the set of extended real numbers strictly greater than bottom (i.e. proper extended-real-valued), and assume `Phi` belongs to `ERealFunction.gammaZero H` (a class of functions with certain convexity/regularity properties). Let `B : H → H` be an operator, let `S` be a subset of `H`, and assume the following hypotheses:

- `alg` is a `ForwardBackwardAlgorithm Phi hPhi B h`. This means `alg` is presumably a sequence `x k` generated by the forward-backward iteration determined by `Phi`, `B`, and the stepsize `h`.
- `hh : 0 < h ∧ h < 2 * beta`, so the stepsize is strictly between `0` and twice the cocoercivity constant `beta`.
- `S` is nonempty.
- `hB : CocoerciveOn beta Set.univ (fun w : Set.univ ↦ B w)`. Interpreting `w : Set.univ` as a point in `H`, this says `B` is `beta`-cocoercive on the whole space.
- `hsolution : ∀ z, z ∈ S ↔ -B z ∈ ERealFunction.subdifferential Phi z`, so `S` is exactly the set of zeros of the sum, equivalently the set of solutions to the inclusion `0 ∈ ∂Phi(z) + B(z)`.

The conclusion asserts that there exists a point `z ∈ S` such that the sequence `alg.x k` converges weakly (in the weak topology on `H`) to `z`: specifically, `Filter.Tendsto (fun k ↦ toWeakSpace ℝ H (alg.x k)) Filter.atTop (nhds (toWeakSpace ℝ H z))`. Thus the forward-backward sequence converges weakly to a solution in `S`.

## Lean proof
```lean
by
  let T : H → H := fun z ↦ ERealFunction.scaledProximityOperator Phi hPhi
    ⟨h, alg.h_pos⟩ (z - h • B z)
  have hfixed : Function.fixedPoints T = S := by
    ext z
    simp only [Function.mem_fixedPoints, Function.IsFixedPt]
    exact ⟨fun hz => (hsolution z).2 (scaled_forward_backward_fixed_implies_solution_local
      Phi hPhi B h alg.h_pos z (by simpa [T] using hz)), fun hz =>
      scaled_forward_backward_solution_implies_fixed_local Phi hPhi B h alg.h_pos z
        ((hsolution z).1 hz)⟩
  have hP : FirmlyNonexpansive
      (ERealFunction.scaledProximityOperator Phi hPhi ⟨h, alg.h_pos⟩) := by
    have hg := ERealFunction.smul_mem_gammaZero Phi hPhi ⟨h, alg.h_pos⟩
    simpa [ERealFunction.scaledProximityOperator] using
      ERealFunction.proximityOperator_firmlyNonexpansive_of_mem_gammaZero hg
  have hF : LipschitzWith 1 (fun z : H ↦ z - h • B z) :=
    forward_step_lipschitz_one_local B beta h hh hB
  have hTlip : LipschitzWith 1 T := by
    have hPlip := lipschitzWith_one_of_firmlyNonexpansive hP
    simpa [T, Function.comp_def] using hPlip.comp hF
  have hC : (Function.fixedPoints T).Nonempty := by rwa [hfixed]
  obtain ⟨p₀, hp₀⟩ := hC
  have hone : 0 < (1 : ℝ) ∧ (1 : ℝ) ≤ 1 := by norm_num
  have hupdate : ∀ n, alg.x (n + 1) = (1 - (1 : ℝ)) • alg.x n +
      (1 : ℝ) • ERealFunction.scaledProximityOperator Phi hPhi ⟨h, alg.h_pos⟩
        (alg.x n - h • B (alg.x n)) := by
    intro n
    simpa using alg.update n
  have hseq₀ := forward_backward_distance_and_residual_tendsto_local
    (ERealFunction.scaledProximityOperator Phi hPhi ⟨h, alg.h_pos⟩) B beta h 1
    hh hone hB hP alg.x hupdate p₀ (by simpa [T] using hp₀)
  have hbounded : Bornology.IsBounded (Set.range alg.x) :=
    bounded_range_of_convergent_distance_to_point hseq₀.1
  have hdist : ∀ z ∈ Function.fixedPoints T, ∃ l : ℝ,
      Filter.Tendsto (fun n ↦ ‖alg.x n - z‖) Filter.atTop (nhds l) := by
    intro z hz
    exact (forward_backward_distance_and_residual_tendsto_local
      (ERealFunction.scaledProximityOperator Phi hPhi ⟨h, alg.h_pos⟩) B beta h 1
      hh hone hB hP alg.x hupdate z (by simpa [T] using hz)).1
  have hcluster : ∀ z : H,
      IsSequentialClusterPt (fun n ↦ toWeakSpace ℝ H (alg.x n))
        (toWeakSpace ℝ H z) → z ∈ Function.fixedPoints T := by
    intro z hz
    rcases hz with ⟨phi, hphi, hphiweak⟩
    have hres : Filter.Tendsto (fun n ↦ alg.x (phi n) - T (alg.x (phi n)))
        Filter.atTop (nhds 0) := by
      simpa [T] using hseq₀.2.comp hphi.tendsto_atTop
    rcases isBounded_iff_forall_norm_le.mp hbounded with ⟨C, hCbound⟩
    have hsubbound : ∃ K : ℝ, ∀ n, ‖alg.x (phi n) - z‖ ≤ K := by
      refine ⟨C + ‖z‖, ?_⟩
      intro n
      calc
        ‖alg.x (phi n) - z‖ ≤ ‖alg.x (phi n)‖ + ‖z‖ := norm_sub_le _ _
        _ ≤ C + ‖z‖ := add_le_add (hCbound _ (Set.mem_range_self (phi n))) le_rfl
    have hphiweak' : Filter.Tendsto
        (fun n ↦ toWeakSpace ℝ H (alg.x (phi n))) Filter.atTop
        (nhds (toWeakSpace ℝ H z)) := by
      simpa [Function.comp_def] using hphiweak
    have hfix : T z = z :=
      nonexpansive_eq_of_tendsto_weakly_of_residual_tendsto_zero_local T hTlip
        (fun n ↦ alg.x (phi n)) z hphiweak' hres hsubbound
    exact hfix
  rcases opial_lemma ⟨p₀, hp₀⟩ alg.x hdist hcluster with ⟨z, hz, hlim⟩
  exact ⟨z, by rwa [← hfixed], hlim⟩
```

## Proof explanation
The proof proceeds by defining the forward-backward operator `T : H → H` by
`T z = ERealFunction.scaledProximityOperator Phi hPhi ⟨h, alg.h_pos⟩ (z - h • B z)`.
Here `⟨h, alg.h_pos⟩` packages `h` together with the positivity of `h` from the algorithm; `alg.h_pos` is the positivity hypothesis already present in `ForwardBackwardAlgorithm`. The term `ERealFunction.scaledProximityOperator` is a scaled proximal operator, and `z - h • B z` is one explicit forward step. The proof then shows several properties of `T`.

First, `hfixed : Function.fixedPoints T = S`. The proof uses `ext z` to reduce to proving equivalence for each point, and then `simp only` expands the fixed-point predicate. Forward and backward implications use two local lemmas: `scaled_forward_backward_fixed_implies_solution_local` and `scaled_forward_backward_solution_implies_fixed_local`, together with `hsolution`. The `by simpa [T] using hz` command rewrites the fixed-point equality `T z = z` in terms of the expansion of `T`.

Second, `P := ERealFunction.scaledProximityOperator Phi hPhi ⟨h, alg.h_pos⟩` is firmly nonexpansive. This follows from `ERealFunction.smul_mem_gammaZero`, which says that multiplying by the positive scalar `h` preserves membership in `gammaZero`, plus `ERealFunction.proximityOperator_firmlyNonexpansive_of_mem_gammaZero`. The proof uses `have hg := ...` to obtain membership and then `simpa [ERealFunction.scaledProximityOperator] using ...` to rewrite the definition of the scaled proximal operator so that the theorem applies directly.

Third, the "forward step" map `z ↦ z - h • B z` is nonexpansive: `hF : LipschitzWith 1 (fun z : H ↦ z - h • B z)`, obtained from the local lemma `forward_step_lipschitz_one_local` using the hypothesis `hh` and the cocoercivity `hB`.

Fourth, since `T` is the composition of a firmly nonexpansive map (hence Lipschitz with constant 1) and a Lipschitz-with-1 forward step map, the proof concludes `hTlip : LipschitzWith 1 T`. The command `simpa [T, Function.comp_def] using hPlip.comp hF` applies the composition law for Lipschitz maps and unfolds the definition of `T`.

Next, the set of fixed points of `T` is nonempty, because it equals `S`, which is nonempty by assumption. The proof states `hC : (Function.fixedPoints T).Nonempty` and obtains a point `p₀` via `obtain ⟨p₀, hp₀⟩ := hC`.

Then the proof checks the parameters needed for the main asymptotic lemma. It sets `hone : 0 < (1 : ℝ) ∧ (1 : ℝ) ≤ 1`, which is a tautology verified by `norm_num`. This parameter `1` plays the role of the averaging coefficient in a relaxed algorithm.

It then proves `hupdate`, the update formula for the sequence `alg.x`. For each `n`,
`alg.x (n + 1) = (1 - 1) • alg.x n + 1 • scaledProximityOperator ... (alg.x n - h • B (alg.x n))`.
This is just a restatement of the standard forward-backward iteration with coefficient `1`; the proof uses `intro n` and `simpa using alg.update n`, where `alg.update n` is the equality supplied by the `ForwardBackwardAlgorithm` structure.

Now the proof applies a local theorem `forward_backward_distance_and_residual_tendsto_local` to obtain two facts, stored in `hseq₀`:
1. The distances `‖alg.x n - p₀‖` converge, giving `hseq₀.1`.
2. The residual `alg.x n - T (alg.x n)` tends to zero, giving `hseq₀.2`.

Because the distances to `p₀` converge, the range `Set.range alg.x` is bounded; this is recorded as `hbounded : Bornology.IsBounded (Set.range alg.x)` using `bounded_range_of_convergent_distance_to_point hseq₀.1`.

The proof then shows that every fixed point of `T` is a point for which the distance sequence converges. For `hdist`, it fixes `z` and a proof that `z` is a fixed point, and applies the same `forward_backward_distance_and_residual_tendsto_local` theorem, again with the point `z`; the resulting first component states that `‖alg.x n - z‖` has a limit.

Next, the proof establishes `hcluster`: every sequential weak cluster point of `alg.x` is a fixed point of `T`. The argument introduces `z` and assumes `hz : IsSequentialClusterPt (fun n ↦ toWeakSpace ℝ H (alg.x n)) (toWeakSpace ℝ H z)`. Unpacking this via `rcases hz with ⟨phi, hphi, hphiweak⟩`, it obtains a subsequence `phi` such that `alg.x (phi n)` converges weakly to `z`. The residual of this subsequence tends to zero:
`Tendsto (fun n ↦ alg.x (phi n) - T (alg.x (phi n))) atTop (nhds 0)`
because it is the composition of the global residual convergence `hseq₀.2` with the subsequence index tending to infinity, as shown by `simpa [T] using hseq₀.2.comp hphi.tendsto_atTop`.

The proof then needs a boundedness hypothesis for the subsequence with respect to `z`. From `hbounded`, it obtains a norm bound `C` for all `alg.x n`. It constructs `hsubbound : ∃ K, ∀ n, ‖alg.x (phi n) - z‖ ≤ K` by taking `K = C + ‖z‖` and using the triangle inequality:
`‖alg.x (phi n) - z‖ ≤ ‖alg.x (phi n)‖ + ‖z‖ ≤ C + ‖z‖`.
This is justified by `norm_sub_le` and `add_le_add`.

Since weak convergence of `alg.x n` along the subsequence is exactly weak convergence of the composed function, the proof records `hphiweak'`.

The key lemma is now applied: `nonexpansive_eq_of_tendsto_weakly_of_residual_tendsto_zero_local` says that if `T` is nonexpansive, a subsequence weakly converges to `z`, the residual `x_n - T x_n` tends to zero, and the subsequence is bounded relative to `z`, then `T z = z`. The command `exact hfix` closes the fixed-point portion.

Finally, the proof invokes `opial_lemma`. This lemma packages the previous facts: the sequence is given, it has bounded range, distances to every fixed point converge, and every weak sequential cluster point is a fixed point. It yields a point `z` with `hz : z ∈ Function.fixedPoints T` and `hlim` stating that `alg.x` weakly converges to `z`. The proof then returns this result. Since `Function.fixedPoints T = S`, it rewrites `hz` using `rwa [← hfixed]` and concludes `∃ z ∈ S, Tendsto ...`, exactly matching the theorem.
